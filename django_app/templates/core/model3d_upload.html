À propos du format OBJ

Le format Wavefront OBJ est un format de fichier texte simple pour les modèles 3D.

Structure typique:

# Commentaire
v x y z        # Sommet (vertex)
vn nx ny nz    # Normale au sommet
f v1 v2 v3     # Face triangulaire
